# SmartStock Vision

Site do projeto de **Laboratório de Inteligência Artificial** (prof. Diego Luis Kreutz, UNIPAMPA, 2026/2).

Autora: Judith Otávia Margarido de Andrade.

Reconhecimento por visão computacional (YOLOv8) dos produtos retirados da prateleira, para apoiar o controle de estoque de pequenos estabelecimentos.
